# practice_py

Python practice notebooks.

## Contents

| Notebook | Topics |
|---|---|
| [`oop.ipynb`](oop.ipynb) | Object-oriented programming, built around an `Employee` class: classes and instances, `__init__`, instance / class / static methods, class variables and attribute lookup, inheritance and `super()`, `isinstance` / `issubclass`, dunder methods (`__repr__`, `__str__`, `__add__`, `__len__`), and `@property` getters, setters, and deleters. |

## Run

Requires Python 3.6+ (f-strings) and Jupyter. No other dependencies.

```bash
jupyter notebook oop.ipynb
```
